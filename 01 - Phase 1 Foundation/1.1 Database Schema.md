## SQL

```sql
-- Users (synced from Clerk on first login)
CREATE TABLE users (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  clerk_id   TEXT UNIQUE NOT NULL,
  email      TEXT NOT NULL,
  name       TEXT,
  plan       TEXT NOT NULL DEFAULT 'free',  -- free | pro
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Searches
CREATE TABLE searches (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    UUID REFERENCES users(id) ON DELETE SET NULL,
  query      TEXT NOT NULL,
  category   TEXT,                         -- food | travel | tech | finance | entertainment
  slug       TEXT UNIQUE,                  -- for /s/[slug] shareable pages
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Individual results per search
CREATE TABLE search_results (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  search_id   UUID NOT NULL REFERENCES searches(id) ON DELETE CASCADE,
  rank        INTEGER NOT NULL,            -- 1, 2, 3
  name        TEXT NOT NULL,
  description TEXT NOT NULL
);

-- Query cache (24h TTL)
CREATE TABLE cache (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  query_hash  TEXT UNIQUE NOT NULL,        -- MD5 of normalized query
  result_json JSONB NOT NULL,
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  expires_at  TIMESTAMPTZ NOT NULL
);

-- Indexes
CREATE INDEX searches_user_id_idx ON searches(user_id);
CREATE INDEX searches_slug_idx ON searches(slug);
CREATE INDEX cache_query_hash_idx ON cache(query_hash);
CREATE INDEX cache_expires_at_idx ON cache(expires_at);
```

---

## Cache Strategy

1. On every `/api/search` call:
   - Hash the query (lowercase + trimmed) → MD5
   - Check `cache` table for a non-expired row
   - If hit → return cached result, skip OpenRouter
   - If miss → call OpenRouter, save to `cache` with `expires_at = NOW() + INTERVAL '24 hours'`

2. Periodic cleanup (or Neon's TTL): `DELETE FROM cache WHERE expires_at < NOW()`
