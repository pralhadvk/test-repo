## Key Flows

### Save flow (in `/api/search`)
```
1. Check cache table (by query hash)
2a. Cache HIT → return cached JSON, log "cache_hit"
2b. Cache MISS → call OpenRouter
3. Save to `searches` + `search_results`
4. Save to `cache` (expires in 24h)
5. Return result
```

### Dashboard page
- Route: `/dashboard` (Clerk-protected)
- Shows: table of past searches, sorted by created_at DESC
- Each row: query text, category, result count, date, "Replay" button
- Replay: clicks fetch cached results by slug (no API call)

---

## Retention Impact

> [!tip] Why this matters for YC
> History + replay = reason to come back.  
> Without this, 3C Search is a one-shot tool, not a product.  
> With this, users return to find their past answers — and that's the D7 retention signal YC wants.
