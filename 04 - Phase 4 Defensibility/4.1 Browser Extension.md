# 4.1 Browser Extension

> Highlight any text on any webpage → right-click → "3C Search this". Replaces Google's built-in search shortcut.

## Why This Is the #1 Defensibility Feature

> [!tip] Extension installs = verified DAU
> YC loves extension metrics because they're hard to fake.  
> Every install is a user who chose to put 3C Search in their browser.  
> Unlike web visits (bots, casual browsers), extension users are genuinely engaged.

---

## manifest.json (V3)

```json
{
  "manifest_version": 3,
  "name": "3C Search",
  "version": "1.0",
  "permissions": ["contextMenus", "tabs"],
  "background": { "service_worker": "background.js" },
  "action": { "default_popup": "popup.html" }
}
```
