## What Was Built (`extension/` folder)

### `manifest.json` (V3)
Permissions: `contextMenus`, `tabs`, `storage`. Popup at `popup.html`.

### `background.js`
Service worker. Creates context menu on install. On click → opens `https://test-repo-seven-lyart.vercel.app/?q={selectedText}` in a new tab.

### `popup.html` + `popup.js` + `style.css`
Mini search UI in the extension popup (360×520px):
- Category selector pills (All / 🍕 / ✈️ / 💻 / 💰 / 🎬)
- Search input with Enter key support
- Results: rank badges + name + description + "↗" Google link
- "Open full →" and "Share link →" buttons after results
- Recent searches (last 5, stored in `localStorage`)
- Pre-fills selected text from the current tab (via `chrome.scripting`)

### How to Load (Developer Mode)
1. Open `chrome://extensions`
2. Enable "Developer mode"
3. "Load unpacked" → select `extension/` folder
