## Key Metrics to Display

| Metric | SQL |
|--------|-----|
| DAU | `COUNT(DISTINCT user_id) WHERE date = today` |
| Search volume | `COUNT(*) FROM searches WHERE date = today` |
| Top queries | `GROUP BY query ORDER BY count DESC LIMIT 10` |
| Pro conversion | `COUNT WHERE plan='pro' / COUNT total users` |
| Cache hit rate | `COUNT cache_hits / COUNT total_searches` |
| Searches per user | `AVG(count) GROUP BY user_id` |
