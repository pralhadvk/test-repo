### `AdminClient.tsx` — Recharts-powered analytics

**KPI Grid (8 cards):**
- All-Time Searches / This Month / This Week / Today
- Active Cache Entries (+ hit rate %)
- Collections Total / API Keys + usage / Curated Results

**Charts:**
- 7-day search volume area chart with gradient fill
- Category breakdown donut pie chart
- Top 10 queries bar chart with relative progress bars
- Affiliate clicks bar chart by program type

**Data Moat section:**
- Shows curated verticals as green pills (vertical + city + count)
- Confirms human-verified quality is deployed

### SQL Queries

```sql
-- 7-day volume
SELECT DATE(created_at), COUNT(*) FROM searches
WHERE created_at > NOW() - INTERVAL '7 days'
GROUP BY DATE(created_at) ORDER BY DATE(created_at);

-- Top queries
SELECT query, category, COUNT(*) as count
FROM searches GROUP BY query, category ORDER BY count DESC LIMIT 10;

-- Category mix
SELECT COALESCE(category, 'uncategorized'), COUNT(*)
FROM searches GROUP BY category;

-- Affiliate CTR
SELECT affiliate_type, COUNT(*) FROM affiliate_clicks GROUP BY affiliate_type;
```
