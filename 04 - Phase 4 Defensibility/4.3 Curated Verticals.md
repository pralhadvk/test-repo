## What Was Built

### DB Schema
```sql
CREATE TABLE curated_results (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  query      TEXT NOT NULL,
  query_hash TEXT UNIQUE NOT NULL,   -- md5(normalized_query)
  vertical   TEXT NOT NULL,
  city       TEXT,
  results    JSONB NOT NULL,
  curated_by TEXT NOT NULL DEFAULT 'human',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Search Flow Integration
`app/api/search/route.ts` now checks curated FIRST:
```
1. md5(normalized_query) → check curated_results
2. If found → return curated (fastest, best quality)
3. Check cache
4. Call OpenRouter
```
Response includes `"curated": true` flag so clients know it's human-verified.
