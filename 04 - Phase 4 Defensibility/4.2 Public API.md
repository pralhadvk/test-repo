## API Design

```http
POST /api/v1/search
Authorization: Bearer sk_3c_...
Content-Type: application/json

{ "query": "best coffee shops in Berlin", "category": "food" }
```

Response:
```json
{
  "query": "best coffee shops in Berlin",
  "results": [
    { "rank": 1, "name": "The Barn", "description": "Specialty coffee pioneer..." },
    { "rank": 2, "name": "Five Elephant", "description": "Roastery and café..." },
    { "rank": 3, "name": "Bonanza Coffee", "description": "Third wave espresso..." }
  ],
  "cached": false,
  "usage": { "queries_today": 5, "queries_remaining": 95 }
}
```
