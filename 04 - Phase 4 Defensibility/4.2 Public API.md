## What Was Built

### `POST /api/v1/search`
- `Authorization: Bearer sk_3c_...` header required
- Validates key against `api_keys` table
- Runs full search (curated → cache → OpenRouter)
- Increments `usage_total` on key row
- Returns `{ query, results, cached, usage: { queries_total, rate_limit } }`
- 100 req/day default rate limit (stored on key row)

### `POST /api/v1/keys`
Generates a new API key (`sk_3c_` + nanoid(32)). Stores in `api_keys` table.

### `/developer` page
Beautiful docs page:
- cURL + JavaScript code examples with syntax highlighting
- Full endpoint reference table (headers, body params, response)
- Rate limits table (Free / Pro / Enterprise)
- "Get API Key" card with label input → generate → copy
- Stores generated keys in `localStorage` for easy access

### DB Schema
```sql
CREATE TABLE api_keys (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  key         TEXT UNIQUE NOT NULL,   -- sk_3c_...
  label       TEXT NOT NULL,
  usage_total BIGINT NOT NULL DEFAULT 0,
  rate_limit  INT NOT NULL DEFAULT 100,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

## API Design

```http
POST /api/v1/search
Authorization: Bearer sk_3c_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json

{ "query": "best coffee in Berlin", "category": "food" }
```

Response:
```json
{
  "query": "best coffee in Berlin",
  "results": [{"rank":1,"name":"The Barn","description":"..."}],
  "cached": false,
  "usage": { "queries_total": 5, "rate_limit": 100 }
}
```
