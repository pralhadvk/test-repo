## What Was Built

### `app/s/[slug]/page.tsx`
Server component. Fetches search + results from `searches` + `search_results` via slug.
- Shows query, 3 ranked results with gold/silver/bronze styling
- "Search this yourself →" links to `/?q=query`
- "Copy link", Twitter, WhatsApp share buttons via `ShareButtons.tsx`
- `generateMetadata()` for SEO title/description

### `app/s/[slug]/ShareButtons.tsx`
Client component. Handles clipboard copy + X/Twitter + WhatsApp deep links.

### `app/s/[slug]/opengraph-image.tsx`
- `runtime = "nodejs"` (uses pg pool directly)
- 1200×630 dark card with gradient glow blobs, query, top 3 as medal list
- Auto-served by Next.js as `og:image` meta tag on `/s/[slug]` pages

### API changes (`app/api/search/route.ts`)
- `persistSearch()` now returns `slug` instead of void
- Awaited on both cache-hit and cache-miss paths
- `slug` included in JSON response → enables immediate share link

const slug = nanoid(8) // e.g. "V1StGXR8"
