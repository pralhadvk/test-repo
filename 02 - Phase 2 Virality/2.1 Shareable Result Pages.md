## Slug Generation

```typescript
import { nanoid } from 'nanoid'
const slug = nanoid(8) // e.g. "V1StGXR8"
// Store in searches.slug column
```

## OG Image (`app/s/[slug]/opengraph-image.tsx`)

```tsx
import { ImageResponse } from 'next/og'
export default async function Image({ params }) {
  const search = await getSearchBySlug(params.slug)
  return new ImageResponse(
    <div style={{ background: '#080c14', padding: 60, width: '100%', height: '100%', display: 'flex', flexDirection: 'column' }}>
      <div style={{ color: '#94a3b8', fontSize: 24 }}>3C Search</div>
      <div style={{ color: 'white', fontSize: 48, fontWeight: 'bold', marginTop: 16 }}>{search.query}</div>
      {search.results.map((r, i) => (
        <div key={i} style={{ color: '#cbd5e1', fontSize: 28, marginTop: 20 }}>
          {i+1}. {r.name}
        </div>
      ))}
    </div>,
    { width: 1200, height: 630 }
  )
}
```

## Why This Is the #1 Priority in Phase 2

> [!tip] Distribution insight
> Every shared link is a free ad for 3C Search.  
> The OG preview shows the query and 3 results — it's inherently interesting.  
> People share it because it makes them look smart for finding a great tool.
