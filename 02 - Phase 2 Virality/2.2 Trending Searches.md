## What Was Built

### `app/trending/page.tsx`
Server component. Accepts `?period=today|week|alltime`. Fetches:
```sql
SELECT query, category, COUNT(*) AS count
FROM searches
WHERE created_at > NOW() - INTERVAL '7 days'
GROUP BY query, category
ORDER BY count DESC LIMIT 25
```
Passes to `TrendingClient` for interactive rendering. `revalidate = 300` (5 min).

### `app/trending/TrendingClient.tsx`
- Period tab row: Today / This Week / All Time (tab links → same page with ?period=)
- Ranked list with animated progress bars (width proportional to count vs. max)
- 🥇🥈🥉 medals for top 3, `#N` for the rest
- Category badge (food/travel/tech/etc.) shown per query
- Click any row → `router.push('/?q=...')` to instantly search it
