## SQL Query

```sql
-- Top 10 queries in last 24 hours
SELECT query, COUNT(*) as count
FROM searches
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY query
ORDER BY count DESC
LIMIT 10;
```
