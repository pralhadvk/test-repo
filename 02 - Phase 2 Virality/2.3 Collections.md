## What Was Built

### DB Schema (Neon)
```sql
CREATE TABLE collections (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name        TEXT NOT NULL,
  is_public   BOOLEAN NOT NULL DEFAULT true,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE collection_items (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  collection_id   UUID NOT NULL REFERENCES collections(id) ON DELETE CASCADE,
  search_id       UUID NOT NULL REFERENCES searches(id) ON DELETE CASCADE,
  added_at        TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(collection_id, search_id)
);
```

### `app/api/collections/route.ts`
POST endpoint: accepts `{ name, query, results }`.
- Creates collection row
- Saves search + results to `searches` + `search_results`
- Links via `collection_items`
- Returns `{ id }` → user directed to `/collections/{id}`

### `app/collections/[id]/page.tsx`
Server component with:
- `generateMetadata()` for SEO title/description
- Shows collection name, item count, created time
- Lists each search with its top 3 results and "View →" link to `/s/[slug]`
- Shareable permalink shown at bottom

### Homepage "Save" button
- Appears in share bar after every search (requires `slug` from API)
- Click → opens `SaveModal` (client component)
- Modal: enter collection name → POST `/api/collections` → show link
- No auth needed — collections are public permalinks

## Note on Auth-gated Features

> [!warning] Phase 3 / Auth upgrade
> Private collections and "My Collections" drawer require Clerk auth (Phase 1.2).
> Until then, collections are always public and accessed only by permalink.
> Users should bookmark their collection URL — we store it in localStorage in Phase 3.

---

## SEO Value

> [!tip] Why collections matter for growth
> A public collection like "Best coffee shops in Bangalore" at `/collections/abc123` gets indexed by Google.  
> Someone searching "best coffee shops bangalore" finds 3C Search organically.  
> This is free acquisition at scale — the more public collections, the more landing pages.
