## What Was Built

### Affiliate Buttons (`app/page.tsx` → `AffiliateButtons` component)
Rendered inline below each result's description, filtered by category:

| Category | Buttons |
|----------|---------|
| Food | Yelp ↗, Maps ↗ |
| Travel | Booking ↗, Google Travel ↗ |
| Tech | GitHub ↗, npm ↗ |
| Entertainment | JustWatch ↗, IMDb ↗ |
| Finance | (none — compliance) |

Click → `POST /api/affiliate-click` (fire-and-forget) → opens URL in new tab.

### `POST /api/affiliate-click`
Records `{ search_id, result_name, affiliate_type }` in `affiliate_clicks` table.

```sql
CREATE TABLE affiliate_clicks (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  search_id    UUID REFERENCES searches(id) ON DELETE SET NULL,
  result_name  TEXT NOT NULL,
  affiliate_type TEXT NOT NULL,
  clicked_at   TIMESTAMPTZ DEFAULT NOW()
);
```
