## What Was Built

### `app/components/CategorySelector.tsx`
5 pill buttons: 🍕 Food · ✈️ Travel · 💻 Tech · 💰 Finance · 🎬 Entertainment.
- Click to select; click again to deselect (returns to "All")
- Selected: `bg-blue-600/20 border-blue-500/50 text-blue-300`
- Unselected: `bg-white/5 border-white/10 text-slate-400`
- Each category has a custom `placeholder` string (imported into homepage)

### Homepage Integration
- CategorySelector rendered above the search box on `app/page.tsx`
- Selected category stored in `category` state
- Passed as `{ query, category, pro }` in POST body to `/api/search`
- Placeholder text changes dynamically: "e.g. best ramen in Tokyo…" for Food

### Enhanced Category Prompts (`app/api/search/route.ts`)

```typescript
const CATEGORY_PROMPTS = {
  food:          "...name, cuisine type, price range hint, and one standout feature...",
  travel:        "...name, best time to visit hint, and one must-do activity...",
  tech:          "...name, key strength, and a one-line use case...",
  finance:       "...name, risk level hint, and one-line rationale. Always end with: 'Not financial advice.'",
  entertainment: "...name, genre/format, and one hook sentence...",
}
```

### Trending Category Filter
Category filter pills added to `/trending` (`TrendingClient.tsx`):
- "All" + 5 category buttons above period tabs
- Client-side filter — no new fetch needed
