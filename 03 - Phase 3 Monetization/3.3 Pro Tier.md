## What Was Built

### `/pricing` page (`app/pricing/page.tsx`)
- Two-column card layout: Free ($0) vs Pro ($9/mo)
- Feature checklist per tier
- "YC ready" badge on Pro card
- Checkout button → `POST /api/stripe/checkout` → redirects to Stripe hosted page
- Success/canceled query param banners
- FAQ row (3 questions)
- If no Stripe keys: button shows error message

### `POST /api/stripe/checkout`
Creates a Stripe Checkout session:
- `mode: "subscription"`, `line_items: [{ price: STRIPE_PRO_PRICE_ID }]`
- `success_url: /pricing?success=true` → sets `localStorage("3cs_pro", "true")`
- `cancel_url: /pricing?canceled=true`
- Returns `{ url }` → frontend redirects

### `POST /api/stripe/webhook`
Handles:
- `checkout.session.completed` → `UPDATE users SET plan = 'pro' WHERE clerk_id = ...`
- `customer.subscription.deleted` → `UPDATE users SET plan = 'free' WHERE clerk_id = ...`
- Validates signature with `STRIPE_WEBHOOK_SECRET`

### Free Tier Rate Limiting
- `localStorage` key: `3cs_searches_{today's date string}` → daily counter
- At 10 searches: `UpgradeModal` appears instead of search
- **Dot tracker** below search box: 10 dots, filled as searches are used
- Counter resets automatically at midnight (new date = new key)

### Pro Features
| Feature | How it works |
|---------|-------------|
| Top 5 results | `/api/search` accepts `{ pro: true }`, sends 5-item prompt to OpenRouter |
| CSV export | Client-side `Blob` download, button appears only for Pro users |
| "Pro" badge | Shows in results header when `isPro = true` |
| Unlimited searches | Skips rate limit check when `localStorage("3cs_pro") === "true"` |

### `UpgradeModal.tsx`
Full-screen modal with feature diff table and "Upgrade to Pro" CTA.
Appears when `!isPro && count >= 10`.

## To Activate Stripe

1. Create a product + $9/month recurring price in Stripe dashboard
2. Copy the Price ID (starts with `price_`)
3. Add to Vercel env vars:
   - `STRIPE_SECRET_KEY=sk_test_...` (or live key)
   - `STRIPE_PRO_PRICE_ID=price_...`
   - `STRIPE_WEBHOOK_SECRET=whsec_...` (from Stripe webhook settings, pointed at `/api/stripe/webhook`)
