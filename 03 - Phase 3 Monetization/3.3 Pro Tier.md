## Free vs Pro

| Feature | Free | Pro ($9/mo) |
|---------|------|-------------|
| Searches/day | 10 | Unlimited |
| Results per search | Top 3 | Top 5 |
| Search history | ✅ | ✅ |
| Collections | Public only | Public + Private |
| Export | ❌ | CSV / PDF |
| API access | ❌ | ✅ |

---

## Stripe Webhook Flow

```
Stripe checkout.session.completed
  → Update users SET plan = 'pro' WHERE clerk_id = ...
  → Send welcome email

Stripe customer.subscription.deleted
  → Update users SET plan = 'free' WHERE ...
```

---

## Conversion Strategy

> [!tip] The upgrade prompt must appear at the right moment
> Don't show it on page load. Show it exactly when the free user hits their 10th search:
> "You've used your 10 free searches today. Upgrade to Pro for unlimited — $9/month."
> Urgency + clear value = highest conversion.
